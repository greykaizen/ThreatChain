SUPPORTED FORMATS:
==================
✓ CSV (.csv)   - Comma-separated values
✓ XML (.xml)   - Structured XML data  
✓ XLSX (.xlsx) - Excel spreadsheet (NEW!)

All formats support:
- Automatic attribute detection
- Type inference
- Data preview
- STIX 2.1 conversion via Knowledge Graph

ERROR HANDLING:
===============
4 error types with detailed messages:
1. Format Error - Unsupported file type
2. Size Error - File exceeds 50MB limit
3. Structure Error - Invalid file structure
4. Content Error - Empty or no valid data

Each error shows:
- Specific error message
- List of issues
- Actionable recommendations
- "View Format Policies" button
