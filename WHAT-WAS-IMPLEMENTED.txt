================================================================================
                          AUTHENTICATION FLOW
================================================================================

REGISTRATION FLOW
-----------------
1. User fills signup form (individual or organization)
2. Frontend sends POST to /api/auth/register/*
3. Backend validates data
4. Backend hashes password with bcrypt
5. Backend creates database record
6. Backend generates JWT token
7. Backend returns token + user info
8. Frontend stores token in localStorage
9. User redirected to dashboard

LOGIN FLOW
----------
1. User fills login form
2. Frontend sends POST to /api/auth/login/*
3. Backend finds user by email
4. Backend verifies password with bcrypt
5. Backend generates JWT token
6. Backend returns token + user info
7. Frontend stores token in localStorage
8. User redirected to dashboard

UPLOAD FLOW (With Auth)
------------------------
1. User must be logged in (has token)
2. User uploads STIX report
3. Frontend sends POST with Authorization header
4. Backend verifies JWT token
5. Backend extracts user/org ID from token
6. Backend saves report with organization_id or user_id
7. Backend creates provenance record with actor info
8. Report is now associated with the user/org

ACCESS CONTROL FLOW
-------------------
1. User requests to view/delete a report
2. Frontend sends request with Authorization header
3. Backend verifies JWT token
4. Backend checks if report belongs to user/org
5. If yes: Allow access
6. If no: Return 403 Forbidden
