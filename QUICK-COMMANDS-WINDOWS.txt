📋 ONE-TIME SETUP
═══════════════════════════════════════════════════════════════
1. Upgrade Node.js to v20+
   → https://nodejs.org/

2. Install MySQL
   → https://dev.mysql.com/downloads/installer/

3. Configure environment
   → copy .env.example .env
   → Edit .env with MySQL password

4. Install & Initialize
   → npm install
   → npm run init-db
   → node scripts/add-gas-columns.js

5. Setup Ethereum
   → .\setup-ethereum-now.bat

═══════════════════════════════════════════════════════════════

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════
Check Node version:
   → node --version

Check MySQL service:
   → Get-Service -Name MySQL*

Start MySQL:
   → net start MySQL80

Check ports in use:
   → netstat -ano | findstr "8545 3001 3000"

Kill process on port:
   → for /f "tokens=5" %a in ('netstat -ano ^| findstr ":3001"') do taskkill /F /PID %a
