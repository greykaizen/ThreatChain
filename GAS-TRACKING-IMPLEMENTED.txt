---

HOW IT WORKS:

When you upload a STIX report:

1. File is processed and hash generated
2. Ethereum transaction is sent (if enabled)
3. Geth returns transaction receipt with:
   - gasUsed: ~50,000-80,000 (actual computation)
   - gasPrice: 0 Gwei (free on private network)
   - gasFee: 0 ETH (calculated: gasUsed × gasPrice)

4. Gas data is stored in blockchain_transactions table:
   - gas_used: Real value from Geth
   - gas_price: 0 (private network)
   - gas_fee: 0 (no cost)

5. Metrics collector reads from database:
   - AVG(gas_used) = Average gas consumption
   - AVG(gas_price) = Average gas price (0 Gwei)
   - AVG(gas_fee) = Average fee (0 ETH)
